## 原生IP、双ISP、三网优化，是三个不同的东西

这三个词经常被并排写在同一张宣传图上，其实各管一件事。

**原生IP（Native IP）**指IP段由英国本土运营商分配，归属地显示为英国，而不是从其他地区广播过来的。它的价值在于"出身正"，平台查归属时不会露出破绽。

**双ISP（Dual ISP）**指同一个IP同时归属两家英国宽带运营商，比如Virgin Media和Sky Broadband。业内的常见说法是双ISP必然是原生IP，原生IP不一定是双ISP，抗封能力比普通原生IP更强一层。这类IP在ipinfo一类的工具里通常显示为Residential。

**三网优化**跟IP属性毫无关系，说的是回程线路对中国大陆电信、联通、移动做了优化，常见方案是CN2 GIA、联通9929、移动CMI/CMIN2。它只影响你从国内连过去快不快。

前两个决定"平台认不认这台机器"，第三个决定"你打开它卡不卡"。买之前先确定哪个是刚需，再看套餐，顺序反了很容易买完才发现用不上。
